# Landing page screenshots

Real captures of the Heads-up 1.4 settings page for the Heads-up page on brandbakery.tech. Headless Chrome, real SF Pro rendering, 2x unless noted. Desktop shots are 1280 CSS px wide with 28 px padding around each element; phone shots are 390 wide.

Demo data only: a throwaway data folder with default settings, the American male voice, one saved location named Home, and five seeded alerts for Brand Bakery Hub and BB Studio. Live facts (Mac volume, output, last input, calls, Focus, ElevenLabs plan usage) are what the Mac reported at capture time. The router's hardware address is masked in the Locations rows. Keys are shown by source only; no key characters appear.
